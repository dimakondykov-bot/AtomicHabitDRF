# Интеграция с телегам ботом

## Создание бота

Найдите в Telegram бота `@BotFather`.

Отправьте команду `/newbot` и следуйте инструкциям (задайте имя и уникальный юзернейм).

Скопируйте полученный API Token (выглядит как `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

## Подключение

В файл переменных окружения `.env` для ключа `TELEGRAM_TOKEN_TG=` добавьте скопированный токен.

Должно получиться так `TELEGRAM_TOKEN_TG=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`

Связать пользователя с чатом `users/link-tg`
